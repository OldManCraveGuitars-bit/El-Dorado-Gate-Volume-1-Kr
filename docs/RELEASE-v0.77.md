# v0.77 한글 패치

- 필드 아이템·돈 획득 시 일본어가 남던 공통 조합 문구 6개를 추가 추출·번역했습니다.
- 상점의 겹치던 수량 제목을 `보유량`으로 줄였습니다.
- `리카바` 계열을 `리커버` 계열로 통일하고, `아이스(회피)`, `히트(마비)`처럼 효과 약칭을 풀어 썼습니다.
- 대사와 아이템 목록의 수요일 카드 이름, 히튼 탱크 표기, 빚 독촉 관련 문맥, 일부 비문을 수정했습니다.
- v0.76은 건너뛰었으며, 추가·수정된 번역 항목은 124개입니다.

원문 대조와 회귀 검사 90개, 편집기 EXE 전체 GDI 빌드 및 섹터 검증을 통과했습니다.
필드 공통 메시지는 네 캐릭터 인덱스의 문자열 조합을 검사했습니다. 실제 필드·상점 화면과 전체 정상 플레이는 추가 검증이 필요합니다.

일본판 v1.002 원본 GDI에 적용합니다. 이전 한글판에 덧씌우지 마세요.
ZIP 전체를 압축 해제한 뒤 패처 EXE에서 원본 GDI와 새 출력 폴더를 선택하세요.
실행 파일 이름은 `DC-El-Dorado-Gate-Volume-1.gdi`입니다.
원본/완성 ROM, BIOS, 시험 VMU, 테스트 입력 어댑터는 포함하지 않습니다.
